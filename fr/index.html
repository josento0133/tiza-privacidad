Politique de confidentialité de Tiza

Dernière mise à jour : 5 octobre 2026

Español · English · Français · Italiano · Deutsch

Qui est responsable

Tiza est une app pour enregistrer vos entraînements en salle, publiée sur Google Play par son développeur. Pour toute question sur la confidentialité, écrivez à josejose0133@gmail.com.

Quelles données l'app conserve

Tout ce que vous saisissez est stocké sur votre téléphone : vos séries et entraînements, routines, poids du corps, profil (taille, âge, sexe, objectif, expérience et séances par semaine), salles et leurs notes, réglages et, si vous configurez l'IA, votre clé API. Tiza n'a ni comptes utilisateur ni serveurs propres : le développeur ne reçoit et ne peut voir aucune de ces données.

Quelles données quittent votre téléphone : l'IA

L'IA est facultative. Elle n'est utilisée que si vous configurez une IA avec votre propre clé API et utilisez l'une de ses fonctions. Tiza envoie alors directement à l'IA choisie, par une connexion chiffrée (HTTPS), les données dont cette fonction a besoin :

  • Améliorer avec l'IA (quand vous le touchez, ou tout seul si vous activez « Améliorer avec l'IA auto ») : votre profil (âge, sexe, taille, objectif et expérience), votre poids, votre salle active (matériel et notes), vos dernières séances de cet exercice, ce que vous avez fait aujourd'hui et, si vous suivez une routine, son objectif et la consigne de cet exercice (séries, répétitions et repos).
  • Recommandation de quoi travailler aujourd'hui : vos entraînements des derniers jours, les noms de vos exercices avec leur groupe musculaire et leur matériel, votre objectif, votre expérience, votre âge et votre sexe, et votre salle active.
  • Analyse IA : l'évolution de vos exercices sur les 60 derniers jours (poids max, séries et volume), le résumé de votre dernière semaine et votre poids.
  • Classer avec l'IA : les noms de vos exercices.

Ces données ne passent par aucun serveur de Tiza. Elles sont reçues et traitées par le fournisseur de l'IA selon sa propre politique :

  • Google (Gemini) : policies.google.com/privacy. Avec le niveau gratuit de l'API Gemini, Google peut utiliser le contenu pour améliorer ses produits.
  • Anthropic (Claude) : anthropic.com/legal/privacy.
  • OpenAI (ChatGPT) : openai.com/policies/privacy-policy.

Autorisations

  • Notifications : pour afficher le compte à rebours du repos, vous prévenir à la fin et, si vous les activez, les rappels d'entraînement.
  • Alarmes et rappels : pour que l'alerte de fin de repos arrive à l'heure écran éteint. Vous pouvez la refuser ; l'alerte peut alors arriver avec un peu de retard.
  • Internet : uniquement pour communiquer avec l'IA choisie.

Sauvegardes

Si vous activez la sauvegarde automatique ou touchez « Sauvegarder maintenant », Tiza enregistre des copies de vos données dans l'app (les 10 dernières) et la dernière aussi dans le dossier Téléchargements de votre téléphone (tiza-backup.db). Cette copie et les fichiers que vous exportez ou partagez ne contiennent pas vos clés API. La copie de Téléchargements est votre fichier : elle n'est pas supprimée quand vous désinstallez l'app ; supprimez-la vous-même si vous n'en voulez plus.

De plus, si la sauvegarde Android est activée, le système peut enregistrer les données de l'app (y compris vos clés API) dans votre compte Google. Tiza n'a pas accès à cette sauvegarde ; elle se gère depuis les réglages de sauvegarde de votre téléphone.

Sécurité, conservation et suppression

Vos données restent sur votre téléphone jusqu'à ce que vous désinstalliez l'app, ce qui les supprime toutes (sauf la copie de Téléchargements, qui est votre fichier). Vous pouvez aussi les supprimer depuis l'app, dans Réglages > Données : Supprimer les entraînements supprime les séries enregistrées, et Supprimer toutes les données supprime aussi votre poids, votre profil, vos routines, vos salles, vos clés API et les copies gardées dans l'app (la langue, le thème et les autres réglages de l'app sont conservés). Votre clé API peut aussi être supprimée seule dans Réglages > IA > Supprimer la clé. Ce qui est envoyé à l'IA est conservé par le fournisseur selon sa politique ; pour le supprimer, adressez-vous à lui. Les connexions avec l'IA utilisent HTTPS et les copies exportées par Tiza ne contiennent pas vos clés API.

Mineurs

Tiza ne s'adresse pas aux personnes de moins de 18 ans.
